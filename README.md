# olist-bi-project

BI project on real e-commerce / logistics data: BigQuery + dbt + Power BI.
Status: work in progress (Week 6).

## Data source and license

- License: CC BY-NC-SA 4.0 (attribution, non-commercial, share-alike).
- The raw data and any transformed tables are NOT in this repo.
- This project is for learning and portfolio only. It is not used for paying clients.

## Setup
Copy `.env.example` to `.env` and set `OLIST_DIR` to the folder that holds the 9 CSV files.
